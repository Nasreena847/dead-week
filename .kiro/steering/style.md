# Dead Week project rules
- Web app using React and Vite. Data is saved in localStorage. No backend.
- Dark, spooky Halloween design: deep purples and blacks, glowing accents, gothic-style fonts for headings, readable body text.
- Mobile-friendly and responsive.
- Keep components small and well named. Add short comments for tricky logic.
- Curse level is always a number between 0 and 100.
- Do not add features beyond what the spec asks for.
